# QuickQR

Create. Customize. Scan. A free, privacy-friendly QR code generator built with Next.js, TypeScript and Tailwind CSS.

## Status

| Phase | Scope | State |
| --- | --- | --- |
| 1 | Foundation: shell, theme, navigation, landing page | Implemented (see PLAN.md) |
| 2 | Generator, validation, live preview | Not started |
| 3 | Customization and export | Not started |
| 4 | Local history | Not started |
| 5 | Scanner and polish | Not started |

The Generator, My QR Codes and Scanner pages are placeholders and say so on screen.

## Run it

```bash
npm install
npm run dev          # http://localhost:3000
npm run lint
npm run typecheck
npm run build
```

Requires Node 20.9 or newer.
